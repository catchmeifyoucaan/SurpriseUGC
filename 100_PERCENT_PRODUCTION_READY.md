## 🚀 **DEPLOYMENT OPTIONS**

### **Option 1: Docker Compose (Local/Staging)**
```bash
# Clone repository
git clone https://github.com/catchmeifyoucaan/SurpriseUGC.git
cd SurpriseUGC

# Configure environment
cp .env.example .env
# Edit .env with your API keys

# Start all services
docker-compose up -d

# Access application
# Frontend: http://localhost:3000
# Backend: http://localhost:8000
# Grafana: http://localhost:3001
```

### **Option 2: Kubernetes (Production)**
```bash
# Create namespace
kubectl create namespace viralforge

# Create secrets
kubectl create secret generic viralforge-secrets \
  --from-literal=database-url=$DATABASE_URL \
  --from-literal=redis-url=$REDIS_URL \
  --from-literal=secret-key=$SECRET_KEY \
  --from-literal=openai-api-key=$OPENAI_API_KEY \
  -n viralforge

# Deploy application
kubectl apply -f k8s/backend/deployment.yaml
kubectl apply -f k8s/frontend/deployment.yaml

# Check status
kubectl get pods -n viralforge
```

### **Option 3: AWS ECS/EKS**
